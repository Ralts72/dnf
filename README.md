## 重建本轮运行资产

仅重新提取或制作资产时需要 Python，先在自己的环境安装 NumPy、Pillow，并把下面的客户端路径换成本机目录：

```sh
python3 -m pip install numpy pillow
python3 tools/dnf_client_analysis/export_audio.py --client "/path/to/client"
python3 tools/dnf_client_analysis/export_r0.py --client "/path/to/client"
python3 tools/dnf_client_analysis/build_r0_scene.py
```

导出器有开发机的历史默认路径，换机时请明确传入 `--client`。它只读取列出的规范包，不依赖定制覆盖包的加载顺序。场景生成器会重写本轮生成的 `.tscn`；若要保留手工调整，应先保存为另一个场景，或将调整同步回生成器。`run_*_storage_checks.py` 的正式存档路径守卫当前按 macOS 实现，Windows 需先适配，已有报告仅代表 Mac 隔离验证。

导出与派生图生成会同步设置无损、无 mipmap 的像素素材导入配置，避免 Godot 自动将 3D 人物首帧改为有损纹理。源文件与派生图可用 `tools/r1/verify_actor_sources.py` 复核，需使用上面的 Pillow Python 环境。

R1 的完整重建入口和导入注意事项见 `docs/R1制作记录.md`。路线和战斗已推进至雕像回廊；后续优先补人偶之王道格里终点战，再结合试玩反馈调整战斗节奏和画面。道格里目前仅完成来源研究，尚未接入游戏。
