# 移动朝向与动作权限方案

日期：2026年10月26日  
状态：本轮讨论的统一设计方案，具体速度、转向范围、窗口、资源与打断条件待原型验证。

角色在地面上支持任意方向移动、转向和出招。手柄以左摇杆提供主要方向输入，锁定维持选中目标；角色的实际移动、身体朝向和攻击指向，根据当前动作与阶段分别决定。

## 基础概念

| 概念 | 表示什么 |
| --- | --- |
| 移动输入 | 玩家希望往哪里移动 |
| 身体朝向 | 角色实际面对的地面方向 |
| 锁定目标 | 当前选中的敌人或允许锁定的怪物部位 |
| 攻击指向 | 此次攻击、射击或法术尝试指向哪里 |
| 动作位移 | 招式自身的停步、踏前、后撤或其他位移 |

这些数据分别保存并按当前动作协调。目标位于高处时，身体通常处理地面朝向；武器、施法点或射击的三维指向按动作能力处理，实际攻击仍受轨迹与范围约束。

## 自由移动与自由攻击

- 左摇杆提供移动方向，角色向行进方向转身。
- 没有方向输入时，默认保留最后朝向。
- 不锁定时，出招方向优先参考当时方向输入；没有输入则参考当前朝向。
- 动作开始后，继续允许多少转向与移动，由该动作及其阶段确定。
- 键鼠映射、摇杆死区和转向平滑参数待确认。

普通自由状态不要求用右摇杆持续独立瞄准。特殊动作的输入需求可单独设计。

## 锁定走位的默认规则

锁定保存目标，不要求空闲移动时身体始终面向它。

- 角色向远离目标的方向移动时，可以转身走开或跑开。
- 停止移动后默认保留当前朝向。
- 目标仍然保持选中，为下一次动作提供参考。
- 目标死亡后默认解除锁定，设置中可开启自动切换附近合适目标；切换不会使已经挥出的攻击突然转向。具体目标筛选及动作阶段衔接待验证。
- 进入有瞄准需求的动作后，可以暂时改用面向目标的移动方式。

这里的“后退”需要区分两种表现：自由走位时转身离开；瞄准或施法时面向目标后撤。具体采用哪种，由当前动作决定。

## 收拔武器与奔跑补充

- 明确区分收武器与持武器状态；喝药及使用道具前需先收武器。使用输入自动衔接收武器与道具动作，已收武器时不重复收起；收武器所需时间保留。
- 提供手动收武器操作，允许提前准备撤离、赶路或使用道具；具体按键与是否提供独立手动拔武器操作待定。
- 收武器时按攻击，一次输入直接衔接拔武器攻击，并保留必要的准备时间；招式按职业设计，不默认附加额外伤害加成。与其他技能、防御动作的衔接另行确定。
- 收武器奔跑采用速度更快的优势，战斗内不因收武器额外降低耐力消耗；具体速度差与消耗数值待验证。
- 脱战奔跑不消耗耐力；战斗内奔跑仍按耐力规则处理。收武器、锁定和战斗状态分别判断，收武器不会自动解除交战。
- 收拔武器的动作阶段、取消和打断，以及与用药、奔跑及重新攻击的衔接，纳入统一动作权限配置。

## 武器子类与战斗切换

- 已确认同一物理剑士专精内，长剑与大剑共享基础攻击模组，主要以速度、动作时长、伤害与手感参数区分，允许战斗切换；不为此拆分职业。
- 蓄势、派生、取消与握持按动作阶段配置，判定匹配实际武器轨迹和可达范围。共享模组不要求所有阶段统一倍速。
- 武器切换不直接抹除已承诺的攻击或收招；切换窗口、成本及冷却待验证。技能页与武器不强制绑定，两组继续共用加点、技能等级、演化和职业资源。
- 其他子类的兼容切换建议与推荐见[主清单](原创游戏设计清单.md)；职业内部列有多种武器，不代表所有组合均已确认可战斗切换，跨专精仍在营地调整。

## 短暂预输入

- 支持短暂预输入，只保留近期的一次有效操作，在动作允许衔接且条件满足时执行，不连续排队多个动作。
- 不因预输入提前开放取消窗口，也不越过受击硬直或资源限制。
- 缓冲时长、输入覆盖与优先级、失效条件待验证，避免旧输入延迟到意外时机执行。

## 资源事件的已确认边界

- 普通主动技能在正式释放事件扣除职业资源；准备阶段被打断不扣，释放后打空仍消耗。具体释放事件逐招配置，不以命中敌人代替释放。
- 持续施法可按时间或效果次数消耗，节奏与资源不足时的处理逐招设计。
- 治疗药与技能扣除规则分别处理：自动收武器阶段不耗治疗药，首次恢复生命时扣整瓶，此后中断停止剩余恢复。
- 上述原则不自动确定具体耐力成本、冷却起算及所有动作的取消权限。

## 近战动作

### 准备阶段

锁定时，出招可以在该招式允许的角度和速度内朝目标调整。目标在背后时，应表现出可读的回身过程；需要先完成多少转向再进入攻击阶段，逐招确定。

发动普通近战后，动作接管移动：可以停步、踏前或采用招式自己的位移。后退输入仍可以保留为玩家意图，但实际位移遵守当前动作权限。

### 生效阶段

挥砍、刺击等生效时，按招式限制继续转向与位移。重攻击更强调方向承诺，轻攻击可以保留较灵活的调整或取消窗口。

锁定不会直接补足距离，也不会让已挥出的武器持续无条件跟随目标。命中使用真实攻击路径与接触部位。

### 收招阶段

按招式开放移动、取消或派生。恢复自由走位后，再根据仍然有效的输入继续行动。

专用撤步斩可以边退边攻击，但需要自己的轨迹、时序、收益和限制。

示例：锁定敌人 → 转身离开攻击范围 → 按近战攻击 → 在允许阶段回身并停步或踏前出招 → 收招后继续走位。

## 格挡姿态

- 第一套基础剑士的普通格挡与弹反共用防御键：按下时有短暂弹反窗口，继续按住保持普通格挡；其他职业可另行设计。具体窗口、重复点按限制及成功或失败后的衔接待验证。
- 弹反成功后提供短暂反击派生机会，玩家按攻击主动发动，也可选择走位、技能或继续防御；不自动播放反击。具体衔接窗口待验证，反击仍按实际距离、接触与敌人状态结算。
- 具备格挡能力时，保持格挡可以慢速后撤或侧移，并维持防御方向，后撤不自动转身露背。
- 快速撤离需解除格挡、闪避或收武器奔跑；具体动作衔接、朝向控制、速度及耐力恢复规则待验证。
- 格挡移动属于当前动作的权限，不改变自由走位时身体朝行进方向转身的基础规则。

## 射击 施法与持续动作

可移动施放时，角色进入该动作的瞄准姿态：身体朝目标或合法攻击方向，移动输入可以变成后撤步与侧步。结束或取消后恢复普通自由移动。

| 动作模板 | 移动候选 | 朝向候选 |
| --- | --- | --- |
| 轻型法术或普通射击 | 允许移动，速度按招式配置 | 面向目标或攻击方向 |
| 持续射击或引导法术 | 允许后撤和侧移，可限制速度 | 在允许转向速度内维持瞄准 |
| 长吟唱 | 可缓慢移动或要求站定，逐招选择 | 按吟唱与释放阶段配置 |
| 高威力蓄力或重型法术 | 关键阶段可以要求停步 | 达到承诺点后限制调整 |
| 专用移动攻击 | 使用明确的动作位移 | 按该招式的轨迹与朝向规则 |

移动施放能力可以属于某个招式或阶段，同一职业也可以同时拥有多种模板。

示例：开始持续射击 → 面向目标 → 向远离目标的方向移动时后撤并继续射击 → 停止或取消射击 → 恢复朝行进方向转身。

射程、弹道、遮挡、部位和实际命中继续生效。维持瞄准、弹体发射后是否追踪、地面法术落点是否固定，是不同规则；后两项尚未统一决定。

## 按动作阶段配置权限

动作可分为准备、生效或持续、收招等阶段。以下字段表示设计意图，具体数据格式待技术设计。

| 配置项 | 含义 |
| --- | --- |
| movement_policy | 自由移动、面向目标的移步、限制移动或由招式接管位移 |
| move_speed_scale | 当前阶段的移动速度范围或倍率 |
| facing_policy | 随移动、朝目标、朝输入或保持已提交方向 |
| turn_rate_limit与turn_angle_limit | 当前阶段允许的转向速度和角度 |
| aim_policy | 攻击指向采用当前目标、输入或已提交方向 |
| motion_source | 使用逻辑位移、动作曲线或根运动等明确来源 |
| interrupt_rules | 哪些操作可以取消、中断或派生 |
| resource_rules | 启动、持续和中断时的资源处理 |
| target_loss_policy | 目标死亡、失效或丢失后的动作处理 |

默认配置可被一组动作复用，特殊招式再覆盖相应阶段。近战、法术和射击通过具体配置表达差异。

已生效的死亡、倒地等强制状态需要明确接管角色控制；哪些攻击能造成这些状态，仍按战斗规则决定。

## 节点与数据职责

- InputController：输出移动意图与动作请求。
- Targeting：保存合法目标与目标点，提供参考方向。
- ActionController：根据动作阶段解析移动、朝向、取消和持续施放权限。
- Locomotion：依据当前权限处理移动意图，并与动作位移协调。
- Player或角色运动入口：统一应用物理位移和解析后的朝向。
- VisualRoot与AnimationTree：表现转身、自由移动、后撤、侧移、施法和攻击。
- Combat与BodyParts：按实际接触和部位完成结算。

同一个时刻，实际移动与朝向分别有明确的写入入口。动作规则、输入逻辑和表现组件通过数据协作，避免各自覆盖角色变换。

根运动与逻辑位移的使用方式待验证；每个阶段的位移来源必须清楚。

## 动画与素材需求

需要根据动作模板准备或适配：

- 自由转身后的正常行走、奔跑。
- 允许移动施放时的后撤步、侧步与相应上身姿态。
- 近战停步、踏前与回身进入攻击的过渡。
- 施放结束、取消后恢复普通移动的过渡。
- 重攻击、重施法关键阶段的稳定支撑姿态。

是否采用上下半身动画分层由动作需求决定。完整身体发力动作与移动射击可以使用不同的动画组织。

素材来源继续采用A（AI直接生成）、B（AI使用软件生产）、C（已有素材后处理）的组合。现成后撤和侧移动作可以重定向修改，缺失过渡通过软件补充，再以实际角色与装备检查。

## 代表性验证场景

- 不锁定时，移动和出招能够覆盖地面各方向。
- 锁定后离开敌人时，身体能朝行进方向转身，目标保持选中。
- 在目标位于背后时发动近战，回身与出手过程清楚。
- 近战生效期间目标移到侧后方，转向遵守当前动作权限。
- 持续按住离开方向并反复出招，动作之间的转身和位移自然。
- 持续射击时可以面向目标后撤和侧移，停止后恢复普通移动。
- 指定为站定的动作阶段正确接管移动。
- 闪避、冲刺、受击等行为按已配置规则影响施放。
- 人形锁定主体，实际命中仍区分头部与其他部位。
- 巨兽高处部位可被选中时，近战仍需满足实际可达条件。
- 目标死亡、丢失、被遮挡或切换时，按对应阶段策略处理。

这些场景用于验证规则一致性与操作感，不预设尚未讨论的具体数值。

## 仍待决定的细节

耐力与受击规则已补充至[原创游戏设计清单](原创游戏设计清单.md)的“耐力与耗尽反馈”“受击 硬直与累计失衡”两节。动作权限需要区分奔跑耗尽喘息、翻滚耗尽喘气、防御破防和普通受击；其中翻滚耗尽后的其他行动权限仍待确认。

- 自由状态与锁定状态的输入映射、转向速度和死区。
- 回身攻击允许的最大转向、准备时间和连续出招表现。
- 各招式的移动速度、位移与承诺点。
- 冲刺、跳跃、闪避、受击对吟唱及持续施放的影响。
- 各招式的具体资源量、释放事件、持续扣除节奏与特殊中断分支；已确认的普通技能释放扣资源原则不再整体视为未定。
- 空中动作的移动与朝向权限。
- 目标丢失、遮挡及无效部位的处理，具体自动换目标筛选与动作衔接；目标死亡默认解锁、可设置自动换目标的原则已确定。
- 瞄准辅助、弹道追踪与落点更新的独立规则。

当前阶段的范围与待执行验收见[设计收敛与首轮验证清单](设计收敛与首轮验证清单.md)。本方案只整理设计和验证方向，保持暂停开发。
