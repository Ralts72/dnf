# 项目概览

更新日期：2026年10月26日  
状态：定位已确认；正式首版内容量与具体实现仍待原型验证。

## 游戏定位

低科技剑与魔法幻想动作角色扮演游戏。完整单人体验，战斗挑战优先，装备养成与探索提供持续游玩的动力。

- 完整单人体验。
- 战斗挑战优先，其次是养成搭配与探索发现。
- 支持重复挑战、获取素材、制作装备和练习打法。
- 成长有明确上限，达到上限后仍可尝试不同职业、装备、技能和挑战。
- 初版目标平台为 Windows PC。
- 手柄优先设计战斗，键鼠完整适配。
- 网络合作、PvP 和联网专项验证均移出初版范围。

## 当前阶段

- 仍在设计整理与单项技术验证阶段，独立原创Godot工程尚未创建。
- 旧DNF复刻内容保持暂停，作为参考保留。
- Demo暂用怪猎模型与可用动作；辟兽模型、骨架及一段动作已在Blender导入和播放，尚未完成Godot战斗验证。
- 首轮只验证基础剑士、人形敌人、巨兽与小型试验场；具体计划见[Demo验证计划](04-原型验证/Demo验证计划.md)。
- 完整愿景、首版覆盖、原型数量和已完成验证分别记录，不用文档篇幅计算制作完成度。

### 镜头方向

暂定采用固定观察方向、中等程度的倾斜俯看。需要兼顾地面纵深、角色前后位置与建筑立面、地形的高度感。

镜头俯角、水平方向、角色屏幕占比、投影方式、跟随、缩放和遮挡处理，通过实机验证确定。

### 美术方向与素材来源

- 写实比例、风格化表现。
- 人物、怪物与建筑保留可信结构，材质与细节适当简化。
- 突出动作轮廓、装备辨识度和环境状态。
- 现成资源打底，通过改造、自制或少量定制补足特色。
- 按统一比例、骨架、材质与动画规范筛选和整合素材。
- AI 协助设计、开发、素材制作与处理。
- 素材生产按三类组合：AI直接生成、AI使用软件生产，以及对AI生成物或现有素材库的后处理。每项素材记录具体生产链。
- 用户目前没有美术技能，素材生产流程需要支持通过参考选择、预览和试玩反馈参与。
- 角色与场景的最终制作流程、渲染方式仍需技术确认。
- 验证Demo阶段暂用《怪物猎人》的模型及可用动作，优先验证本作玩法；已完成普通辟兽模型、骨架及一段原作动作的Blender导入与播放验证。人物角色模型后续再获取与验证，此次不启动提取。临时素材不决定正式职业、怪物和美术设定，正式素材生产路线后续再定。

素材类别、生产路线与首批验证样本详见[素材生产方案](03-制作规范/素材生产方案.md)。验证Demo的临时素材路线已选定，正式素材来源、完整工具链与数量仍待确定。

## 工程与投入

- 新建独立原创工程。
- 现有 DNF 复刻工程保留作参考，内容扩展保持暂停。
- 经验证的通用逻辑可按需复用。
- 用户主导决策和验收，AI协助设计、开发与素材处理。
- 用户稳定投入按每周约15小时规划。
- 资金预算暂不作为当前规划约束。
- 完成日期与制作效率根据实际验证结果估算。

新工程的引擎版本、目录、代码架构、数据格式和资产规范尚未正式确定。当前已完成设计整理与单项资产技术验证，尚未创建原创工程。

## 长期方向

网络双人合作与PvP保留为未来方向，当前不继续细化。

网络合作暂记：

- 各自设备、各自镜头。
- 以房主世界为准。
- 客人满足剧情条件时共同推进；条件不满足时可协助并获得奖励。

这些方向不构成初版交付要求。
