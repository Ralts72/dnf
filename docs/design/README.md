## 维护规则

- 已确认是设计方向成立；已验证必须有实际结果；两者不互相替代。
- 暂定允许后续调整；待定不作默认实现；工程建议与剧情草案不自动升级为确认结论。
- 完整愿景、首版范围、Demo数量和实际完成状态分别表述。
- 同一条详细规则只维护在对应玩法专题，其他文档摘要并链接；正文直接写规则，不保留脱离问题语境的“A／B／C”答案标签。素材生产方式的A／B／C是正式分类，继续保留。
- 当前工作目录中的怪猎提取物、工具、Blender文件和视频不随设计文档推送；验证记录保留来源与边界。

## 本次整理

旧的单份《原创游戏设计清单》已拆为玩法与世界专题；原型计划不再复写整套规则。剧情实例、开源参考和素材验证日志移到各自目录。当前初版一把战斗武器、一页装配技能、三个攻击键与短派生，无通用自由跳跃，生活制作走菜单；法术按用途区分双重消耗，同时只激活一个狩猎任务。道具采用LT＋右摇杆选择、R3确认的轮盘，仅实际选物时明显减速，具体以专题和[待办与决策](04-原型验证/待办与决策.md)为准。
