# Demo验证计划

更新日期：2026年10月26日  
状态：V0有局部素材证据；V1、V2尚未开发与验收。

## 当前阶段

当前按“素材与技术样例 → 核心战斗 → 短循环”推进。完整愿景与首版范围见[项目概览](../项目概览.md)，规则以[玩法专题](../README.md#玩法规则)为准，本文件只维护阶段范围和验收。

当前不创建原创新工程、不恢复旧DNF复刻。已获授权并完成辟兽的本地素材样本验证；后续玩法开发仍需具体任务指令。整理文档不增加制作完成度，也不等于原型整体通过。

## 验证顺序

### V0：素材与技术样例

目标是确认当前设想能否生产和导入，而不是先做最终角色。

- 建议一个人形基底供玩家与人形敌人使用，两个可替换衣甲样例，覆盖移动、攻击、防御和受击的最小动作集合。
- 一件可用武器；共享模组的参数样本可用于验证长剑与大剑原则，不要求先完成暂缓的正式武器子类表和整套装备树。
- 一个已有骨架和动作的巨兽候选，检验转身、进攻、部位挂点与受击；物种与最终外观未定。
- 小场景内检查角色比例、镜头、高度、遮挡、衣甲穿插、武器握持、导出回导与动作事件。
- 环境样例采用火源点燃木料、持续燃烧并损毁，湿润影响点燃难度；检验反馈与保存恢复，具体阈值、传播和灭火参数待定。
- 每件样例沿用A直接生成、B软件制作、C后处理的生产链记录，列明来源、输入输出与已检查项。

退出条件：能给出可复用的资产规格草案、实际预览结果与缺陷清单。当前仅完成辟兽的Blender模型、骨架与单段动作验证，已留存预览和限制说明，详见[怪猎资产验证](怪猎资产验证.md)。这不代表V0整体通过，人物、贴图、完整动作集合、Godot接入和其他样例仍待验证。

### V1：核心战斗原型

测试内容使用功能代号或工作名，不提前锁定正式职业技能与首领设定。

本轮已确认：基础攻击至少轻、重两个独立按键，可蓄力重击长按。第三个特殊攻击键：先预留，待轻重攻击、蓄力和基础攻防试玩后再决定是否加入与具体功能，不列为首轮必做动作。若后续采用，按此前方向单按触发。首个人形采用持剑无盾普通士兵，首个巨兽采用四足兽型；具体造型、尺寸与动作尚未锁定。

后续确认：第一套剑士普通攻击每次按键执行一次或推进一段，不按住自动重复；士兵偶尔主动格挡且有明确破绽；四足样例背高暂按角色1.5～2倍验证，其余比例及最终造型待定。

攻击结构补充：三段轻击作为基础，同时按招式规则支持轻、重、蓄力与候选特殊攻击连携；具体派生表未定，不把三段基线当作整套固定连招，也不默认持续控制敌人。当前用辟兽作临时资产样本；其原作体型、招式或骨架不冻结正式怪物设定。

| 对象 | 建议的最小样例 | 主要验证问题 |
| --- | --- | --- |
| 玩家 | 基础移动、奔跑、跳跃、闪避、轻重攻击、格挡与弹反、主动反击、收武器与基础药品 | 输入、承诺、资源与攻防取舍是否能共同成立 |
| 人形 | 持剑无盾普通士兵，偶尔格挡并有明确破绽；普通直接攻击、较强攻击，以及一种需要不同处理的威胁作为候选 | 走位、防御与闪避有无各自用途，普通连击是否频繁造成无解失控 |
| 巨兽 | 四足兽型，背高约角色1.5～2倍，优先检查头、前肢、躯干的接近与打点；有方向承诺的攻击、显著位移或范围威胁；一个可打弱点、一个可破坏结构、一个高处目标点作为候选 | 尺寸、镜头、实际可达、部位失衡及破坏是否易理解 |
| 场地 | 开阔地、墙角、坡道或高差、少量遮挡物 | 不同位置是否出现判断与控制失真；不制作完整大陆路线 |
| 反馈与调试 | 生命、耐力、职业资源及必要目标反馈；可重置与查看命中部位、动作阶段和状态 | 能区分规则错误、素材问题和手感问题 |

先验证基础攻防与命中，再加一个资源技能及兼容武器／技能页切换样例，检验共同资源和加点边界；不用为此制作完整技能树、全套职业试用或玩家训练场成品。

退出条件：完成下列验收场景并留下实际结果；修复规则不一致后由用户试玩判断手感。当前所有项目均未执行。

### V2：短循环原型

- 使用一个安全整备点、短探索路线与已有战斗样例，降低新增内容干扰。
- 建议只选一条装备路线，覆盖初始、普通强化和节点升级三个可对比状态；检查属性提升与使用等级条件。
- 获取指定素材、查看配方、制作或培养、装备、再次挑战能够串通；具体材料和数值是测试配置，不是正式经济定稿。
- 在真实库存中验证药品携带、使用、休整补给和首领重试返还；战斗内始终禁止制作。
- 增加一条简化装备取舍，如一件替代武器或一个珠子样例，判断改变配置是否带来可理解差异。
- 若只有数值碾压、重复操作或供给失控，先修循环，不直接扩展完整商店、生活技能和大量掉落表。

退出条件：用户能完成一次准备、出发、挑战、培养和再战，说明收获改变了什么，并愿意尝试下一次。仍不预先固定单个首领必须打几分钟。

## 首轮验收场景

以下是待执行的验收计划，不是已通过的测试或自动化测试实现。

| 编号 | 场景 | 应观察到的结果 |
| --- | --- | --- |
| C01 | 自由移动、锁定后转身离开、回身攻击 | 身体朝向与选中目标分开；回身有过程，已承诺攻击不突然追背后目标 |
| C02 | 目标在范围外或高处，近战攻击 | 锁定不补足距离或高度，不产生幽灵命中 |
| C03 | 人形锁主体，实际攻击不同身体或防护部位 | 接触部位决定结果，调试与反馈相符；不出现头部锁定切换 |
| C04 | 正常命中巨兽部位、暂停进攻躲避、再命中 | 交战间隔不无故清空部位积累；伤害、失衡、破坏分别可辨认 |
| C05 | 同类攻击分别用走位、闪避、普通格挡和弹反处理 | 结果遵守招式配置；成功一次不抹去后续攻击；弹反后不自动反击 |
| C06 | 攻击收招前提前输入，另试受击中输入 | 近期单次缓冲在合法时机执行，不排成长队或跳过受击与承诺 |
| C07 | 奔跑、翻滚、承受格挡攻击分别耗尽耐力 | 正耐力最后一滚完整执行，翻滚耗尽不额外罚站；奔跑耗尽喘息与防御破防分别处理，恢复参数按注明的测试值执行 |
| C08 | 主动技能准备阶段被打断、释放后打空 | 前者不扣职业资源，后者扣资源；不把命中当作唯一扣除点 |
| C09 | 持武器喝药、生效前取消、生效后取消 | 自动收武器；首次恢复前不耗药，之后扣整瓶并停止剩余恢复；恢复前慢后快 |
| C10 | 兼容武器与技能页切换 | 不产生第二份加点、资源或技能等级，不清除已承诺收招；实际武器与判定一致 |
| C11 | 镜头遮挡、巨兽靠近边缘或高处部位 | 玩家与关键威胁可判断；遮挡淡化不改变实体碰撞或投射阻挡 |
| C12 | 首领失败重试、主动放弃及普通探索死亡 | 按各自规则处理；未胜利不发本次部位奖励，不复制物品或双退投入 |
| C13 | 对同一敌人进行再次挑战 | 玩家能说明站位、出手或防御改进带来的收益，初步排除只能靠装备数值取胜的问题 |

受控对照时可使用固定测试配置区分伤害来源，不能据此删除正式设计中的概率暴击或固定装备差异。参数、镜头和防御收益需有具体测试版本，不能用“感觉已经差不多”代替记录。
