## 当前阶段

当前按“素材与技术样例 → 核心战斗 → 短循环”推进。完整愿景与首版范围见[项目概览](../项目概览.md)，规则以[玩法专题](../README.md#玩法规则)为准，本文件只维护阶段范围和验收。

当前不创建原创新工程、不恢复旧DNF复刻。已获授权并完成辟兽的本地素材样本验证；后续玩法开发仍需具体任务指令。整理文档不增加制作完成度，也不等于原型整体通过。

## 验证顺序

### V0：素材与技术样例

目标是确认当前设想能否生产和导入，而不是先做最终角色。

- 建议一个人形基底供玩家与人形敌人使用，两个可替换衣甲样例，覆盖移动、攻击、防御和受击的最小动作集合。
- 一件可用武器；共享模组的参数样本可用于验证长剑与大剑原则，不要求先完成暂缓的正式武器子类表和整套装备树。
- 一个已有骨架和动作的巨兽候选，检验转身、进攻、部位挂点与受击；物种与最终外观未定。
- 小场景内检查角色比例、镜头、高度、遮挡、衣甲穿插、武器握持、导出回导与动作事件。
- 环境样例采用火源点燃木料、持续燃烧并损毁，湿润影响点燃难度；检验反馈与保存恢复，具体阈值、传播和灭火参数待定。
- 每件样例沿用A直接生成、B软件制作、C后处理的生产链记录，列明来源、输入输出与已检查项。

退出条件：能给出可复用的资产规格草案、实际预览结果与缺陷清单。当前仅完成辟兽的Blender模型、骨架与单段动作验证，已留存预览和限制说明，详见[怪猎资产验证](怪猎资产验证.md)。这不代表V0整体通过，人物、贴图、完整动作集合、Godot接入和其他样例仍待验证。

### V1：核心战斗原型

测试内容使用功能代号或工作名，不提前锁定正式职业技能与首领设定。

当前基础攻击采用轻、重、特殊三个独立输入，可蓄力重击长按；原型先打磨轻重攻防，再接入少量RT动作与短派生，特殊动作的具体功能仍需验证。初版一把战斗武器、一页装配技能，不做通用自由跳跃、战斗换武器或第二技能页。首个人形采用持剑无盾普通士兵，首个巨兽采用四足兽型；具体造型、尺寸与动作尚未锁定。

后续确认：第一套剑士普通攻击每次按键执行一次或推进一段，不按住自动重复；士兵偶尔主动格挡且有明确破绽；四足样例背高暂按角色1.5～2倍验证，其余比例及最终造型待定。

攻击结构补充：三段轻击作为基础，同时按招式规则支持轻、重、蓄力与候选特殊攻击连携；具体派生表未定，不把三段基线当作整套固定连招，也不默认持续控制敌人。当前用辟兽作临时资产样本；其原作体型、招式或骨架不冻结正式怪物设定。

| 对象 | 建议的最小样例 | 主要验证问题 |
| --- | --- | --- |
| 玩家 | 基础移动、奔跑、闪避、轻重特殊攻击与少量短派生、格挡与弹反、主动反击、收武器与基础药品；情境跨越及少量招式离地按具体样例验证 | 输入、承诺、资源与攻防取舍是否共同成立；不依赖自由跳跃、完整空中连段或多技能页 |
| 人形 | 持剑无盾普通士兵，偶尔格挡并有明确破绽；普通直接攻击、较强攻击，以及一种需要不同处理的威胁作为候选 | 走位、防御与闪避有无各自用途，普通连击是否频繁造成无解失控 |
| 巨兽 | 四足兽型，背高约角色1.5～2倍，优先检查头、前肢、躯干的接近与打点；有方向承诺的攻击、显著位移或范围威胁；单区多阶段，并提供疲劳等低压状态；一个可打弱点、一个可破坏结构、一个高处目标点作为候选 | 尺寸、镜头、实际可达、部位失衡与破坏，以及阶段和缓冲是否易理解 |
| 场地 | 开阔地、墙角、坡道或高差、少量遮挡物 | 不同位置是否出现判断与控制失真；不制作完整大陆路线 |
| 反馈与调试 | 生命／体力、耐力、法力、招式资源及必要目标反馈；可重置与查看命中部位、动作阶段和状态，资源恢复方案待统一后配置 | 能区分规则错误、素材问题和手感问题 |

先验证三键基础攻防、少量派生与命中，再加一个资源技能及一页技能装配样例，检验基础派生与独立技能的用途、资源和加点边界；武器及装配在安全整备时调整，不制作战斗双武器或第二技能页，不用为此制作完整技能树、全套职业试用或玩家训练场成品。

退出条件：完成下列验收场景并留下实际结果；修复规则不一致后由用户试玩判断手感。当前所有项目均未执行。

### V2：短循环原型

- 使用一个安全整备点、短探索路线与已有战斗样例，降低新增内容干扰。
- 建议只选一条装备路线，覆盖初始、普通强化和节点升级三个可对比状态；检查属性提升与使用等级条件。
- 获取指定素材、查看配方、制作或培养、装备、再次挑战能够串通；具体材料和数值是测试配置，不是正式经济定稿。
- 在真实库存中验证药品携带、使用、休整补给和首领重试返还；战斗内始终禁止制作。
- 增加一条简化装备取舍，如一件替代武器或一个珠子样例，判断改变配置是否带来可理解差异。
- 若只有数值碾压、重复操作或供给失控，先修循环，不直接扩展完整商店、生活技能和大量掉落表。

退出条件：用户能完成一次准备、出发、挑战、培养和再战，说明收获改变了什么，并愿意尝试下一次。仍不预先固定单个首领必须打几分钟。

## 首轮验收场景

以下是待执行的验收计划，不是已通过的测试或自动化测试实现。

| 编号 | 场景 | 应观察到的结果 |
| --- | --- | --- |
| C01 | 自由移动、锁定后转身离开、回身攻击 | 身体朝向与选中目标分开；回身有过程，已承诺攻击不突然追背后目标 |
| C02 | 目标在范围外或高处，近战攻击 | 锁定不补足距离或高度，不产生幽灵命中 |
| C03 | 人形锁主体，实际攻击不同身体或防护部位 | 接触部位决定结果，调试与反馈相符；不出现头部锁定切换 |
| C04 | 正常命中巨兽部位、暂停进攻躲避、再命中 | 交战间隔不无故清空部位积累；伤害、失衡、破坏分别可辨认 |
| C05 | 同类攻击分别用走位、闪避、普通格挡和弹反处理 | 结果遵守招式配置；成功一次不抹去后续攻击；弹反后不自动反击 |
| C06 | 攻击收招前提前输入，另试受击中输入 | 近期单次缓冲在合法时机执行，不排成长队或跳过受击与承诺 |

| C10 | 一把武器、一页技能与三键短派生，另在安全整备更换兼容武器或装配技能 | 基础派生不占独立技能槽，装配技能有额外战术用途；战斗中不切武器或第二技能页，不产生第二份加点或资源；安全整备调整后按实际武器检查技能兼容性与判定；LT＋RB与LT＋RT暂不分配，生活技能通过菜单进入 |
| C11 | 镜头遮挡、巨兽靠近边缘或高处部位 | 玩家与关键威胁可判断；遮挡淡化不改变实体碰撞或投射阻挡 |

| C23 | 对具备暗杀资格、不同生命与防护的测试敌人发动暗杀；安排外来攻击覆盖接近、正式动作、结束后及无效请求，对照动作前后的资源 | 伤害按装备、命中部位和防护等配置计算，不直接跳过生命判定；弱敌可击杀、较强敌人可存活并进入后续遭遇，不因暗杀提示承诺必杀；正式动作从起手至收招全程免伤且不受击打断，接近、无效输入、正式开始前及结束后不享受该保护；暗杀不额外发放资源恢复奖励，不套用处决回耐力与招式资源，通用恢复按正常条件处理；资格、倍率和提示按测试配置执行 |
| C24 | 比较带削耐属性的攻击命中格挡／未格挡人形、人形耐力未空／归零、破甲前后、合法／超出距离的B输入，选择处决或普通输出；安排外来攻击，并测试主角招式资源为空及无效请求 | 大部分攻击可通过命中削减人形耐力，不要求先打中格挡；人形用同一可读耐力条判断归零处决机会，命中削耐不保证立即打断；破甲降低耐力上限且自然恢复不越过新上限，主角不受同类破甲及上限削减；普通硬直或破甲本身不绕过归零直接提示；削耐量、上限削减、叠加及当前值同步配置后再验收；超距不长距离滑移，符合条件可选B或自由输出，处决不保证击杀；正式动作全程免伤、不中断，动作前后正常受击，失败B无保护／奖励；不额外扣招式资源、不以空格数禁止发动，有效执行一次性恢复耐力与共用招式资源，默认不恢复生命或法力；恢复量与发放节点待原型验证，初版巨兽不做通用处决 |
| C25 | 漏捡已生成的重要装备或配方后离开、死亡返回、保存读取，再到营地领取；对照已现场拾取、未开宝箱、未完成任务与未胜利首领战 | 有领取资格的重要掉落进入营地待领，现场拾取与营地领取不复制同一物品；保存读取不重复登记或领取；未开宝箱、未完成任务及未胜利的待结算部位奖励不被提前发放，纯练习也不生成成长奖励；具体转移与入口按测试配置执行 |
| C26 | 脱战后菜单取消狩猎，另试交战中退出及在整备点重新接取或更换委托 | 脱战可直接取消而不强制回营地；交战中先按既定主动放弃战斗流程退出，消耗仍按原遭遇结算；重新接取或更换必须在整备点完成，同时只激活一个狩猎任务；目标生成及撤出按配置执行，不在眼前突然出现或消失，取消也不发放尚未取得的胜利奖励 |
| C27 | 主角受伤后观察实际HP与灰血，等待自然恢复，另试实际HP耗尽、药品与自然恢复同时发生及再次受到直接生命伤害 | 受伤后只将配置的部分损失登记为可恢复生命，自然恢复不超过剩余灰血或生命上限，不把所有缺血自动补满；再次受到直接生命伤害时丢弃旧灰血，按新伤生成可恢复部分，不累计旧灰血也不额外扣同等实际HP；实际HP归零仍按死亡处理，灰血不作为护盾；药品与自然恢复不重复恢复同一段生命；比例和动作恢复条件配置后再验收，不将本条视为已运行 |

受控对照时可使用固定测试配置区分伤害来源，不能据此删除正式设计中的概率暴击或固定装备差异。参数、镜头和防御收益需有具体测试版本，不能用“感觉已经差不多”代替记录。

## 后续职业与训练场验证

出现第二个可用职业后，再验证同等级切换时按当前职业重算基础属性，不保留练级职业的永久成长、不通过反复切换叠加，装备定义与培养状态不受改写。具体成长曲线、当前资源与技能点衔接按届时配置验收。

玩家训练场具备试用入口后，验证尚未正式解锁的已制作职业可以使用预设装备与技能试用，离场不带出预设装备或试用技能，也不改变正式职业解锁记录。本节是后续验收计划，不扩张当前V1的基础剑士范围，也不代表已实现或已测试。
