# 怪猎耐力参考

更新日期：2026年10月26日  
状态：基础原作资料已查阅；本作采用规则与未实测的原作细节分别标注。

## 核对范围

用户要求耐力耗尽后的行动参考怪猎。此次查阅的[卡普空《崛起／曙光》官方手册](https://game.capcom.com/manual/MHRISE/en/switch/page/4/1)明确了奔跑、回避消耗耐力及耐力随时间恢复；[《Generations》官方手册](https://game.capcom.com/manual/MH_Gen/en-UK/page-24.html)也给出了相关基础规则。

上述页面没有逐项说明“翻滚刚好归零后能否攻击／用道具”“奔跑跑空的全部取消条件”和不同武器、版本的例外。本次未启动本机游戏做输入实测，也不把社区概括写成全系列已经实测一致的结论。原作细节需要时再指定版本核对。

## 本项目采用的适配规则

在既定设计上采用按消耗动作区分后果的参考思路，具体规则主要维护在[战斗与操控](../01-玩法规则/战斗与操控.md)：

| 导致耗尽的行为 | 本作处理 |
| --- | --- |
| 单次翻滚 | 正耐力允许最后一滚，归零后当前动作完整结束；不另加全操作锁死，其他动作按自身条件执行 |
| 战斗中持续奔跑 | 耗尽前有无力、喘气预警；仍坚持跑空时进入已确认的短暂强制喘息 |
| 承受格挡攻击 | 耐力不足以维持防守时破防，不等同于奔跑喘息 |

普通攻击通常不耗耐力；部分招式、持续状态依自身配置处理。道具仍需收武器和使用动作，技能仍受职业资源与动作条件约束。脱战奔跑不耗耐力、没有随时间下降的耐力上限，继续沿用本项目既定方向，不因参考怪猎而自动改动。

恢复延迟、各动作是否暂停恢复、奔跑重新启动阈值和喘息时长仍是测试参数；这不撤销已确认的最后一滚与连点防御规则。
