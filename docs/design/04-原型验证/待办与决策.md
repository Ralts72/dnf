## 下一轮优先讨论

## 已定事项，不重复提问

| 事项 | 当前结论 | 定义位置 |
| --- | --- | --- |
| 三个攻击键 | X轻、Y重／蓄力、RT特殊；少量有用途的短派生承担常态动作，特殊攻击具体功能待样例验证 | [战斗与操控](../01-玩法规则/战斗与操控.md) |
| B场景动作与处决 | B统一当前明确提示的互动／情境跨越、收武器拾取及条件性暗杀／处决；LT＋B仍为装配技能，旧LB＋Y处决映射移除，Y保留重击蓄力 | 同上 |
| 潜行与暗杀定位 | 辅助绕行、处理小怪与取得开战优势，主要首领仍以正面交锋为主；具体资格与倍率待设计，伤害模型及战斗处决按后续各行维护 | 同上 |
| 暗杀伤害 | 高额伤害结算，装备、命中部位及防护参与；普通小怪通常可杀、强敌可能重创，不承诺必杀，不新增等级差压制；具体资格与倍率待设计 | 同上 |
| 暗杀动作保护 | 正式动作开始至结束全程无敌，起手、生效与收招均不受伤害或受击打断；接近、失败输入及正式开始前无保护，结束后恢复正常受击 | 同上 |
| 暗杀资源奖励 | 不额外恢复资源，主要收益为高额先手伤害；不套用处决的耐力与共用招式资源奖励，通用资源恢复仍按正常条件处理 | 同上 |
| 人形处决判定 | 按可读耐力条统一判断，消耗与恢复整体参照主角，归零产生处决机会；可放弃处决而自由输出，不保证击杀；具体耗耐及归零窗口待配置 | 同上 |
| 人形命中削耐 | 大部分攻击带削韧／削耐属性，有效命中即可削减人形敌人耐力，不仅格挡受击才降低；自身出招成本、命中削耐与单次硬直分别配置，不增加并列处决架势条 | 同上 |
| 耐力自然恢复 | 主角与人形敌人一致，仅站立或普通行走时恢复；攻击、防御、翻滚及奔跑期间不自然恢复，格挡移动也不恢复；基础攻击仍通常不扣自身耐力，巨兽疲劳独立处理 | 同上 |
| 人形破甲与耐力上限 | 人形敌人防护破甲同时降低耐力上限，自然恢复以新上限为界；处决仍看归零；主角不适用防护破坏及其上限削减，幅度与叠加待配置 | 同上 |
| 大型怪物处决范围 | 初版不做通用处决，保留行动疲劳与部位失衡／破坏、自由打点；不采用不恢复的处决长耐力条；额外资源奖励及少数剧情终结仍为候选 | 同上 |
| 处决动作保护 | 处决正式开始至结束全程无敌，包含起手、生效、收招；输入失败、接近目标与开始前不享受保护，结束后恢复正常受击；暗杀已另行确认相同保护 | 同上 |
| 处决资源方向 | 不额外扣共用招式资源、不以剩余格数作为门槛；有效处决恢复耐力与共用招式资源，默认不恢复生命或法力，每次执行只结算一次；具体数量和节点待原型验证 | 同上 |
| A与L3机动 | 无方向A蹲伏／起身、有方向A翻滚；L3切换奔跑且不强制收刀，持武器较慢、收武器较快，RB仍可收刀后奔跑；脱战免费、交战耗耐 | 同上 |
| 单武器与一页技能 | 初版一把战斗武器、一页装配技能，武器及装配在安全整备时调整；不切第二页，LT＋RB与LT＋RT暂不分配 | 同上 |
| 自由跳跃与情境跨越 | 初版取消通用自由跳跃，B统一互动／情境跨越；收刀奔跑朝有效障碍或限定间隙前进时也可自动跨越，共用安全落点与动作权限检查；保留少量招式自带离地 | 同上；[探索与环境](../01-玩法规则/探索与环境.md#低矮障碍与翻越) |
| 生活技能入口 | 生活技能、调制等直接走菜单，不设专门生活快捷键或轮盘；场景采集与工坊继续B交互，原有制作条件不变 | 同上 |
| 道具轮盘 | LT＋右摇杆选择、R3使用、松开取消；实际展开选物时明显减速，确认使用或关闭后恢复正常，LT单独按住不减速；上键治疗、其余十字键暂留空 | [补给与复归](../01-玩法规则/补给与复归.md) |
| 最后一次翻滚 | 剩余耐力大于零即可发动，消耗归零，动作完整执行 | [战斗与操控](../01-玩法规则/战斗与操控.md) |
| 连点防御 | 不刷新当前弹反窗口；成功后可主动衔接下一次防御 | 同上 |
| 弹反耐力成本 | 空按和成功弹反不单独扣耐力；普通格挡受击按规则扣耐力 | 同上 |
| 零耐力弹反 | 能够正常行动时允许尝试；不取消喘息或受击等限制，失败照常受击或破防 | 同上 |
| 弹反资源奖励 | 成功弹反加快共用招式资源充能，具体收益待测试 | 同上 |
| 攻击性质分类 | 斩击、钝击、投射；剑刺、枪刺暂归斩击，元素承伤分别配置 | 同上 |
| 肉质与弹刀 | 参考怪猎的部位与攻击性质承伤；少数明确硬部位弹刀，普通防护主要减伤；初版暂不做斩味和磨刀 | 同上 |
| 首领战结构 | 单区、多阶段；通过怪物疲劳、喘息等低压状态缓冲；暂不制作换区机制，具体阶段与行为待定 | 同上 |
| 常规首领转阶段 | 以血量阈值为主，各首领分别配置阶段数、阈值与行为变化 | 同上 |
| 转阶段时机 | 达到阈值后等合法衔接点再切换，不无条件中断当前招式、受击或倒地状态；特殊剧情例外单独配置 | 同上 |
| 连跨阶段阈值 | 常规首领到合法衔接点后直接进入当前血量对应阶段，允许跳过中间阶段，不强制逐段补演 | 同上 |
| 多阶段血量 | 共用一条总血条，转阶段不回满 | 同上 |
| 怪物疲劳来源 | 怪物自身行动消耗耐力，连续高消耗招式后疲劳；玩家攻击能否加速疲劳后续再定 | 同上 |
| 怪物疲劳表现 | 明确短暂喘息→低频进攻、较大破绽→恢复常态 | 同上 |
| 共用资源 | 统一为体力／生命HP、耐力、法力、招式资源；招式资源替代旧剑士职业资源，不额外保留该资源池；连段连携不耗招式资源，施法仍耗法力 | 同上 |
| 招式资源计量 | 分格储存，主动招式消耗一格或多格；总格数及各招式消耗待试玩 | 同上 |
| 招式资源恢复 | 时间充能为主，逐格依次恢复；有效进攻与成功弹反加快当前充能格 | 同上 |
| 法术双重消耗 | 基础、常用法术主要耗法力；强力爆发、控制或特殊机动法术再同时消耗招式资源，不要求所有装配法术双耗；具体清单与成本待配置 | [战斗与操控](../01-玩法规则/战斗与操控.md) |
| 治疗移动 | 用药时可减速走动、减速奔跑；奔跑本身不取消治疗，沿用正常耗耐规则 | [补给与复归](../01-玩法规则/补给与复归.md) |
| 治疗快捷键 | 默认自动推荐适合当前血量的可用治疗药，也可手动指定 | 同上 |
| 自动选药范围 | 默认常规药包含高级基础药，珍贵特殊应急药默认手动；推荐范围可调整 | 同上 |
| 首领重试整备 | 可直接快速再战，也可先安全调整装备、技能及加点或载入配装，再重新挑战 | 同上 |
| 普通敌人刷新 | 普通小兵、小型怪物可以刷新，不再因地点完成／清空统一永久停刷；任务与首领结果保留，重大事件可调整生成内容 | 同上 |
| 地点完成判定 | 完成该地点关键目标即可，不要求杀光所有固定敌人；完成记录不统一决定普通小怪能否刷新 | 同上 |
| 整备点再挑战 | 提供狩猎任务与再挑战入口；可重复狩猎首领由接取任务激活并在任务地点出现，具体生成与任务流程待设计；一次性首领重战仅用于练习 | [挑战与通关后](../01-玩法规则/挑战与通关后.md) |
| 一次性首领的装备循环 | 人物或怪物均按世界唯一性处理；真实首胜解锁相关制作体系，后续由其他可重复怪物等供给素材；不反复击杀唯一存在，不由重战产出成长奖励 | 同上 |
| 狩猎任务场地 | 常规狩猎在真实探索地图的指定区域激活目标，利用已解锁传送与捷径前往；特殊竞技场可单独组织 | 同上 |
| 狩猎任务激活数 | 同时只激活一个狩猎任务，可保留多个待接委托，单个任务可以有多个目标；主线、故事支线和普通收集任务照常并行 | [挑战与通关后](../01-玩法规则/挑战与通关后.md) |
| 狩猎取消与更换 | 脱战后可在菜单取消；重新接取或更换仍在整备点完成，保持单个激活任务；交战时先按主动放弃战斗处理，消耗沿用既有规则 | 同上 |
| 狩猎完成与返回 | 完成全部目标后结算，玩家留在现场继续探索或脱战后按正常规则传送；无强制返回倒计时，不因完成自动补满消耗品或在现场刷新下一只目标 | 同上 |
| 纯练习消耗 | 练习胜利、失败或主动结束均恢复进入前的消耗品库存，不免费补满，不带出成长奖励；真实狩猎仍按正常规则结算 | 同上 |
| 人形首领武器惊喜 | 唯一人物真实首胜可随机获得成品，否则取得受损原物／关键残件并确定性修复，修复后同规格性能一致；可复制设计可制作，非唯一人形精英保留稀有同款的重复随机掉落 | [装备与经济](../01-玩法规则/装备与经济.md) |
| 重要掉落漏捡 | 已实际产生且有领取资格的未拾取装备、配方等重要掉落转至营地待领，现场与营地不重复领取；未开宝箱、未完成任务、未胜利的部位奖励及练习成长奖励不计入 | 同上 |
| 大地图动态内容 | 敌人与随机事件可持续补充，重大世界事件可改变生成条件与内容；固定据点清空不使整个大地图停止动态生成 | [补给与复归](../01-玩法规则/补给与复归.md) |

| 死亡再战语音 | 死亡后重返或重新挑战时，按人物认知及遭遇配置特殊短语音 | [补给与复归](../01-玩法规则/补给与复归.md) |
| 翻滚耗尽后权限 | 不额外强制罚站；其他动作按自身条件执行，奔跑跑空和破防另行处理 | [战斗与操控](../01-玩法规则/战斗与操控.md)；原作核对范围见[耐力参考](怪猎耐力参考.md) |
