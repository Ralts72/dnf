## 历史范围与规则收敛

| 项目 | 本轮统一结果 |
| --- | --- |
| 旧的两区域、2～3职业数量与新五大陆四职业 | 分成完整愿景与旧数量基线，正式首版覆盖仍未定 |
| 武器细分已写表却又暂缓 | 表整体标为暂缓草案；仅保留用户已确认的长剑大剑共享与切换原则，不据表开工 |
| 双配置曾被理解为双职业或两套完整加点 | 同一专精、共同加点与资源；武器和技能页不强绑；跨专精留在营地 |
| 所有装备长期培养的早期概括 | 稀有度达到条件或可制作才进入长期培养，普通杂装除外；等级、强化和稀有度分开 |
| 把全部喝药移动表现列为候选 | 基础治疗药慢速移动已确认；其他道具逐项设计 |
| 移动文档仍将资源扣除、目标死亡全部列为待定 | 同步已确定的释放扣资源与死亡默认解锁／可选自动换目标，仅留下具体参数和其他失效情况 |
| 分解返还、自定义强化回退与分支改选 | 分别计算，珠子拆装仍免费；不能合成一个通用全额返还承诺 |
| 共用联系人曾等于共用唯一寻人目的 | 各人独立诉求，共同联系人作为阶段线索，正常探索没有隐藏怠慢判定 |
| 大师很强却仍需主角、仍会失联 | 精通职业不等于全知或具备复归资格；知识缺口、留守隔离和侵蚀共同解释局限 |

剧情中的守门者、旧阵和具体救援解法仍是草案，不能因为流程完整就当作正式世界事实冻结。
