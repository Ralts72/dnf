# 挑战与通关后

更新日期：2026年10月27日  
状态：重复挑战与通关后成长方向已确认；数量、阶段和参数待定。

## 重复挑战

- 基础世界的敌人强度固定。
- 后续通过明确的进阶挑战再次利用地区与敌人，提供对应素材和奖励。
- 进阶阶段有上限。
- 进阶挑战难度方式：少量行为变化加适度数值提升，调整招式组合或增加少量新的应对点，同时保留怪物原有规律。
- 不要求每个阶段重做整套怪物，也不以普遍加速、延长连击或单纯堆高生命值作为主要提升手段；具体变化逐个敌人设计。
- 场地条件、额外目标与敌人组合仍可作为补充变化，不以随机挑战词缀作为本轮确定的主要方式。
- 发现、解锁目标后支持快速再挑战，减少反复走完整探索路线的负担。
- 再挑战前可先安全整备，调整装备、技能或载入配装，也可直接沿用当前方案；具体流程见[补给与复归](补给与复归.md#首领重试前的战前整备)。
- 普通小兵、小型怪物可刷新，不再以地点完成／清空统一禁止其重生；任务、剧情及首领的实际世界结果持久保留。整备点提供狩猎任务与再次挑战入口，具体组织见下文，唯一任务奖励不因重复入口自动重复发放。
- 重复游玩的核心包含熟悉动作、判断机会与掌握职业带来的提升。
- 怪物组合、场地、额外目标、装备等变化可以补充体验，具体任务形式待设计。

Boss 战斗时长仍需验证。此前讨论过的熟练玩家3～4分钟、普通玩家6～7分钟没有被最终确定，不作为首版验收标准。

当前首领战以单区、多阶段组织，暂不制作怪物换区，通过疲劳、喘息等低压状态提供缓冲。先验证压力起伏和整备机会，再据试玩确定总时长；具体战斗规则见[战斗与操控](战斗与操控.md)。

## 整备点的再次挑战

### 任务驱动的首领狩猎

- 在整备点选择已解锁的狩猎任务，激活后对应首领怪物才在任务地点出现；首领不随普通小怪的休整刷新一起重生。常规狩猎主要使用真实探索地图的指定区域，保留世界连续性，通过已经解锁的传送节点与捷径快速前往；特殊竞技场等任务可单独使用独立场景，不将全部狩猎默认改为独立副本。
- 同时只激活一个会生成狩猎首领的任务，可保留多个待接委托；单个狩猎任务可以包含多个目标。该限制不阻止主线、故事支线或普通收集任务并行，也不将一个狩猎任务机械地等同于一只敌人。
- 可重复狩猎的怪物可解释为追猎同种的不同个体；委托包含发现踪迹、确认活动区域及处理目标，接取任务是玩法上的生成条件，不必在故事中表现为委托凭空创造怪物。具体任务文本、登场方式和活动范围待设计。
- 完成该次狩猎的全部目标后结算经验与狩猎素材，玩家留在现场，可以继续探索、采集或脱战后按[正常传送规则](探索与环境.md#快速传送的启动条件)返回已解锁地点；不设置完成后自动回营地的倒计时，也不因任务结束自动补满消耗品。
- 再接对应任务可再次挑战；已完成的主线目标、一次性事件和独特人物命运不会因此逆转。真正唯一的剧情存在不默认通过同种个体反复生成；完成狩猎本身不会立即在现场刷新下一只目标。
- 再战前可调整装备、技能及加点，沿用[战前整备](补给与复归.md#首领重试前的战前整备)和真实库存规则；失败快速重试沿用原规则，正常狩猎胜利不会自动返还本次成功尝试的消耗。
- 脱战后可通过菜单取消当前狩猎委托，不要求先返回整备点；重新接取或更换委托仍在整备点进行，并继续遵守同时只激活一个狩猎任务的限制。战斗中如要退出，先走既定的主动放弃战斗流程；不因取消委托另设一套补给结算，沿用各遭遇已有规则。
- 失败后快速重试、取消当前委托与完成后再次接取分别管理；具体可用整备点、解锁条件、委托保存与追踪、目标生成／撤出时机及奖励表待设计，不默认接任务或取消时让首领在玩家面前突然出现或消失。

### 一次性首领的制作解锁与重战

已确认：按目标是否在世界中唯一、是否能够真实重复挑战来组织奖励，不只按人形或怪物区分。一次性的人物首领和独特怪物均适用本节。

- 首次真实胜利或对应任务节点确定性解锁相关制作体系，载体可以是一次性核心、工艺记录或制作资格；具体载体按首领及世界设定设计。一次性解锁不得要求在后续制作中反复消耗多份只能从该唯一首领取得的材料。
- 解锁后的系列制作、强化与节点升级消耗其他可重复怪物素材、矿物或相应阶段材料，不要求再刷一次性首领。真正唯一的遗物仍按唯一物品处理，不因解锁某系列就默认允许复制所有原物。
- 人物首领的武器可随机直接获得成品，未获得成品时可沿确定性路线修复或制作；真正唯一的原武器通过受损原物／关键残件修复同一件，修复后的同规格性能一致。具体规则见[装备与经济](装备与经济.md#人形首领武器的惊喜掉落)。制作体系必定解锁，不等同于所有成品首次必掉。
- 首次击败后在整备点解锁战斗回顾，只提供再次体验、练习和测试配装，不承担永久装备、素材、经验等成长产出，也不重抽真实首战的随机战利品。候选解释为回忆或演练，具体表现及是否需要特殊设施待定，不逆转现实中的人物存亡。
- 纯练习重战结束后，胜利、失败或主动结束均恢复至进入练习前的消耗品库存，练习不产生可带回的物品或成长收益；恢复本次消耗不等于免费补满药品包，不额外生成库存。真实首战和有产出的狩猎任务继续沿用自己的消耗与奖励规则。
- 基本入口可统一为整备点的挑战列表，清楚区分“狩猎任务”的真实产出与“战斗回顾”的练习用途。菜单、补给规则与可用目标需清楚展示，具体解锁与难度配置待设计。
- 不再推进此前“残响凝结共鸣素材、用于制作强化”的候选方案；可重复素材获取由真实狩猎与其他已确定来源承担。

## 通关后的爬塔类挑战

- 永久推进型，逐层解锁并保留阶段进度，可重复挑战已开放层级获取素材。
- 延续角色等级、装备、技能点与配装成长，不以每轮从零积累临时强化作为基础结构。
- 楼层变化：固定框架、有限变化。阶段主题、关键首领与主要素材来源稳定，普通楼层可调整敌人组合、场地条件或目标，具体变化池待设计。
- 玩家应能明确选择对应阶段定向刷取素材；关键首领保持可学习的核心规则，不随每次进入随机改变攻击性质，不因此引入局内随机升级体系。
- 优先通过敌人组合、场地与目标变化丰富挑战，仍需符合已确定的怪物行为与有限进阶设计。
- 通关后素材与装备来源：爬塔与世界中的少量高阶目标并存，包括可选高阶委托、隐藏敌人或探索目标；保留地区基础强度，不将整张地图普通敌人统一替换成高等级版本。
- 爬塔新增装备较少，成长主要通过高阶素材，将此前取得且具备长期培养资格的装备升级到最高装备等级，不以反复用全新装备淘汰旧装备作为主要循环。
- 总层数、阶段划分、检查点、失败重试、奖励与素材分布及具体场景形式待设计，不自动确定每层均可直接传送。
- 表现与主要奖励关系：通关即可取得该挑战定义的主要奖励，不按完成时间、受击次数或用药表现评分分档，不采用评分显著决定日常素材收益的结构。
- 奖励数量与随机掉落仍按各自掉落表确定；此前已确定的部位破坏、指定狩猎目标及特殊委托奖励保持原规则，不将其混同为综合表现评分。

## 爬塔的补给与整备节奏

- 数层组成一个阶段，阶段内延续消耗，到检查点才能补给、切换职业及调整完整配装。
- 阶段不宜过长，重要首领前设置整备与快速重试点，避免首领失败后反复清理整段路线。
- 阶段内仍允许既定的脱战有限制作，消耗携行素材，不直接调用仓库；战斗中禁止制作。
- 普通楼层失败处理：返回阶段检查点，重置当前阶段的普通楼层，保留更早已解锁的阶段进度；重要首领仍按其前置整备与快速重试规则处理，不要求失败后重爬整段普通楼层。
- 阶段应较短，具体阶段层数、检查点位置、返回与再次进入方式、退出中断保存及资源结算待设计。
- 退出中断：允许脱战中断续玩，保存当前阶段位置、已完成楼层及剩余补给，下次继续；不恢复已消耗补给，不将主动退出等同于死亡重置。
- 死亡仍按阶段失败规则处理，不保存半场战斗；具体可保存节点、读档与覆盖规则待设计。

死亡、重试返还、休整刷新和存档见[补给与复归](补给与复归.md)。装备长期培养资格与节点升级见[装备与经济](装备与经济.md)。
