# 设计收敛与首轮验证清单

日期：2026年10月26日  
状态：首轮文档收敛与验证计划；已完成辟兽的Blender模型、骨架及单段动作技术验证，核心战斗原型尚未开发或验收。  
用途：将整体设想、稳定规则、待定项与首批验证分开，作为下一轮讨论和任务拆解入口。

玩法规则以[原创游戏设计清单](原创游戏设计清单.md)为主要记录；人物与剧情详见[主线与复归者群像构想](主线与复归者群像构想.md)。本文件负责阶段范围、顺序与验收，不另建一套相互竞争的玩法规则。

## 1. 本轮结论

总体方向已经能说明游戏希望提供什么体验，当前缺口主要是范围和具体验证内容。保留五大陆、四职业和群像故事作为完整愿景；下一步先把首个原型写成可执行任务，不继续默认扩充职业、武器、地图或系统数量。

当前不创建原创游戏新工程、不恢复旧 DNF 复刻、不制作正式资产。后续授权的辟兽素材技术验证已经执行，工具与产物留在独立验证目录。讨论继续可以修改设计；以下验证数量是建议样例规模，不等于已批准整体开工或正式首版总量。

设计准备仍维持约60%的粗略阶段判断；整理文档不等于已经验证战斗、资产或制作效率，不据此自动提高游戏完成度。

## 2. 稳定方向：作为后续取舍依据

| 领域 | 当前依据 |
| --- | --- |
| 核心体验 | 完整单人、中速且有分量、站位与真实打点、同时对抗人形和巨兽；避免长时间控制敌人后持续输出的连段主导 |
| 镜头 | 暂用已接受的倾斜固定观察方向作比较基准，需能辨认纵深、高度、敌人动作与部位；角度、投影及最终画面须实测 |
| 移动与攻击 | 地面任意方向；锁定选目标，普通走位可转身离开；攻击在允许阶段调整朝向，关键阶段有承诺，命中受距离与路径约束 |
| 防御与资源 | 闪避、格挡、弹反和走位各有价值；耐力与职业资源分开；基础剑士防御键短按窗口弹反、按住格挡，成功后主动选择反击 |
| 命中与受击 | 锁定点、实际接触部位、伤害、失衡与破坏分开；人形只锁主体，巨兽可锁部位；身体或防护差异影响承伤 |
| 职业成长 | 剑士、法师、猎手、暂定御灵者；各保留物理、魔法专精；营地换已解锁职业，战斗仅当前专精内配置，共用加点 |
| 武器切换 | 长剑与大剑共享基础攻击模组，允许同一物理专精内战斗切换；其余细分表暂缓讨论，不据此批量制作 |
| 装备循环 | 固定属性与特色、素材制作主线、少量成品惊喜；普通强化、节点升级、珠子与有限定制；不随机洗词条、不强化失败 |
| 装备边界 | 装备自身等级与最低使用等级对应；普通强化不提高该等级，节点升级提高；达到稀有度门槛或可制作才有长期培养资格，普通杂装除外 |
| 药品与补给 | 有限携带、来自制作购买与真实库存，无免费补满主治疗；使用需收武器和动作；战斗禁制作；治疗与法力药共用药品包，战术道具另包 |
| 探索与环境 | 广泛环境属性交互为方向，环境常规辅助战斗；具体覆盖需验证，不等于所有对象完整持续模拟或所有建筑可摧毁 |
| 世界与人物 | 五方大陆、四方主要人物、各有个人诉求；地域与血统不锁玩家职业；联系人真心帮助、全职业精通但非全知 |
| 失败体验 | 缩短再战路程，保留已得成长；封闭首领快速重试与普通探索死亡分开处理；正常探索不触发隐藏怠慢失格 |

这份稳定方向不要求每项出现在第一个试验场，也不代表内部参数与具体例子已经锁定。

## 3. 收敛后的范围分层

| 层次 | 内容 | 当前处理 |
| --- | --- | --- |
| 完整愿景 | 五大陆、四大职业及至少八个物理魔法专精方向、四人群像、完整冒险与通关后成长 | 保留；不直接当成首批任务数量 |
| 首批技术与资产样例 | 一个角色基底、少量换装、武器挂点、动作导入、一个巨兽样本与部位、小环境反应样例 | Demo暂用怪猎模型与可用动作；辟兽已完成Blender样本验证，人物模型后续获取，引擎表现尚待验证 |
| 核心战斗原型 | 基础剑士、一个人形、一个巨兽、小型试验场、必要HUD与调试、快速重置 | 已有验证方向；具体动作和测试参数还要形成任务卡 |
| 短循环原型 | 小范围探索、获得素材、制作或培养一条装备路线、再次挑战 | 战斗初步成立后接入，避免同时建设完整经济和世界 |
| 正式首版 | 开放哪些大陆局部、哪些职业专精、序章、装备及支线、环境与生活内容量 | 未定；旧数量是讨论基线，不提前宣称完整五大陆或八专精全部交付 |
| 明确后续 | 联机合作、PvP、完整居民作息等时间模拟扩展；装备耐久后续再评估 | 不加入初版前置条件 |

五大陆的愿景没有被删成一个试验场；试验场也没有被扩成需要先制作整套世界才能启动。

## 4. 按证据推进的验证顺序

### V0：素材与技术样例

目标是确认当前设想能否生产和导入，而不是先做最终角色。

- 建议一个人形基底供玩家与人形敌人使用，两个可替换衣甲样例，覆盖移动、攻击、防御和受击的最小动作集合。
- 一件可用武器；共享模组的参数样本可用于验证长剑与大剑原则，不要求先完成暂缓的正式武器子类表和整套装备树。
- 一个已有骨架和动作的巨兽候选，检验转身、进攻、部位挂点与受击；物种与最终外观未定。
- 小场景内检查角色比例、镜头、高度、遮挡、衣甲穿插、武器握持、导出回导与动作事件。
- 环境另取一条明确反应链，检验属性变化、传播或交互、反馈与保存恢复；具体反应和材料先另定，不扩成完整生态。
- 每件样例沿用A直接生成、B软件制作、C后处理的生产链记录，列明来源、输入输出与已检查项。

退出条件：能给出可复用的资产规格草案、实际预览结果与缺陷清单。当前仅完成辟兽的Blender模型、骨架与单段动作验证，已留存预览和限制说明，详见[素材类型与生产建议](素材类型与生产建议.md)。这不代表V0整体通过，人物、贴图、完整动作集合、Godot接入和其他样例仍待验证。

### V1：核心战斗原型

测试内容使用功能代号或工作名，不提前锁定正式职业技能与首领设定。

本轮已确认：基础攻击至少轻、重两个独立按键，可蓄力重击长按。第三个特殊攻击键已选择 A：先预留，待轻重攻击、蓄力和基础攻防试玩后再决定是否加入与具体功能，不列为首轮必做动作。若后续采用，按此前方向单按触发。首个人形采用持剑无盾普通士兵，首个巨兽采用四足兽型；具体造型、尺寸与动作尚未锁定。

后续确认：第一套剑士普通攻击每次按键执行一次或推进一段，不按住自动重复；士兵偶尔主动格挡且有明确破绽；四足样例背高暂按角色1.5～2倍验证，其余比例及最终造型待定。

攻击结构补充：三段轻击作为基础，同时按招式规则支持轻、重、蓄力与候选特殊攻击连携；具体派生表未定，不把三段基线当作整套固定连招，也不默认持续控制敌人。四足样例是否采用熊兽型及对应的怪猎体态参考仍在讨论，尚未锁定实际骨架。

| 对象 | 建议的最小样例 | 主要验证问题 |
| --- | --- | --- |
| 玩家 | 基础移动、奔跑、跳跃、闪避、轻重攻击、格挡与弹反、主动反击、收武器与基础药品 | 输入、承诺、资源与攻防取舍是否能共同成立 |
| 人形 | 持剑无盾普通士兵，偶尔格挡并有明确破绽；普通直接攻击、较强攻击，以及一种需要不同处理的威胁作为候选 | 走位、防御与闪避有无各自用途，普通连击是否频繁造成无解失控 |
| 巨兽 | 四足兽型，背高约角色1.5～2倍；有方向承诺的攻击、显著位移或范围威胁；一个可打弱点、一个可破坏结构、一个高处目标点作为候选 | 尺寸、镜头、实际可达、部位失衡及破坏是否易理解 |
| 场地 | 开阔地、墙角、坡道或高差、少量遮挡物 | 不同位置是否出现判断与控制失真；不制作完整大陆路线 |
| 反馈与调试 | 生命、耐力、职业资源及必要目标反馈；可重置与查看命中部位、动作阶段和状态 | 能区分规则错误、素材问题和手感问题 |

先验证基础攻防与命中，再加一个资源技能及兼容武器／技能页切换样例，检验共同资源和加点边界；不用为此制作完整技能树、全套职业试用或玩家训练场成品。

退出条件：完成下列验收场景并留下实际结果；修复规则不一致后由用户试玩判断手感。当前所有项目均未执行。

### V2：短循环原型

- 使用一个安全整备点、短探索路线与已有战斗样例，降低新增内容干扰。
- 建议只选一条装备路线，覆盖初始、普通强化和节点升级三个可对比状态；检查属性提升与使用等级条件。
- 获取指定素材、查看配方、制作或培养、装备、再次挑战能够串通；具体材料和数值是测试配置，不是正式经济定稿。
- 在真实库存中验证药品携带、使用、休整补给和首领重试返还；战斗内始终禁止制作。
- 增加一条简化装备取舍，如一件替代武器或一个珠子样例，判断改变配置是否带来可理解差异。
- 若只有数值碾压、重复操作或供给失控，先修循环，不直接扩展完整商店、生活技能和大量掉落表。

退出条件：用户能完成一次准备、出发、挑战、培养和再战，说明收获改变了什么，并愿意尝试下一次。仍不预先固定单个首领必须打几分钟。

## 5. 首轮验收场景

以下是待执行的验收计划，不是已通过的测试或自动化测试实现。

| 编号 | 场景 | 应观察到的结果 |
| --- | --- | --- |
| C01 | 自由移动、锁定后转身离开、回身攻击 | 身体朝向与选中目标分开；回身有过程，已承诺攻击不突然追背后目标 |
| C02 | 目标在范围外或高处，近战攻击 | 锁定不补足距离或高度，不产生幽灵命中 |
| C03 | 人形锁主体，实际攻击不同身体或防护部位 | 接触部位决定结果，调试与反馈相符；不出现头部锁定切换 |
| C04 | 正常命中巨兽部位、暂停进攻躲避、再命中 | 交战间隔不无故清空部位积累；伤害、失衡、破坏分别可辨认 |
| C05 | 同类攻击分别用走位、闪避、普通格挡和弹反处理 | 结果遵守招式配置；成功一次不抹去后续攻击；弹反后不自动反击 |
| C06 | 攻击收招前提前输入，另试受击中输入 | 近期单次缓冲在合法时机执行，不排成长队或跳过受击与承诺 |
| C07 | 奔跑、翻滚、承受格挡攻击分别耗尽耐力 | 奔跑喘息、翻滚限制与破防不是同一状态；未决分支先按注明的测试规则执行 |
| C08 | 主动技能准备阶段被打断、释放后打空 | 前者不扣职业资源，后者扣资源；不把命中当作唯一扣除点 |
| C09 | 持武器喝药、生效前取消、生效后取消 | 自动收武器；首次恢复前不耗药，之后扣整瓶并停止剩余恢复；恢复前慢后快 |
| C10 | 兼容武器与技能页切换 | 不产生第二份加点、资源或技能等级，不清除已承诺收招；实际武器与判定一致 |
| C11 | 镜头遮挡、巨兽靠近边缘或高处部位 | 玩家与关键威胁可判断；遮挡淡化不改变实体碰撞或投射阻挡 |
| C12 | 首领失败重试、主动放弃及普通探索死亡 | 按各自规则处理；未胜利不发本次部位奖励，不复制物品或双退投入 |
| C13 | 对同一敌人进行再次挑战 | 玩家能说明站位、出手或防御改进带来的收益，初步排除只能靠装备数值取胜的问题 |

受控对照时可使用固定测试配置区分伤害来源，不能据此删除正式设计中的概率暴击或固定装备差异。参数、镜头和防御收益需有具体测试版本，不能用“感觉已经差不多”代替记录。

## 6. 冲突与版本变化的处理

| 项目 | 本轮统一结果 |
| --- | --- |
| 旧的两区域、2～3职业数量与新五大陆四职业 | 分成完整愿景与旧数量基线，正式首版覆盖仍未定 |
| 武器细分已写表却又暂缓 | 表整体标为暂缓草案；仅保留用户已确认的长剑大剑共享与切换原则，不据表开工 |
| 双配置曾被理解为双职业或两套完整加点 | 同一专精、共同加点与资源；武器和技能页不强绑；跨专精留在营地 |
| 所有装备长期培养的早期概括 | 稀有度达到条件或可制作才进入长期培养，普通杂装除外；等级、强化和稀有度分开 |
| 把全部喝药移动表现列为候选 | 基础治疗药慢速移动已确认；其他道具逐项设计 |
| 移动文档仍将资源扣除、目标死亡全部列为待定 | 同步已确定的释放扣资源与死亡默认解锁／可选自动换目标，仅留下具体参数和其他失效情况 |
| 分解返还、自定义强化回退与分支改选 | 分别计算，珠子拆装仍免费；不能合成一个通用全额返还承诺 |
| 共用联系人曾等于共用唯一寻人目的 | 各人独立诉求，共同联系人作为阶段线索，正常探索没有隐藏怠慢判定 |
| 大师很强却仍需主角、仍会失联 | 精通职业不等于全知或具备复归资格；知识缺口、留守隔离和侵蚀共同解释局限 |

剧情中的守门者、旧阵和具体救援解法仍是草案，不能因为流程完整就当作正式世界事实冻结。

## 7. 剩余问题按时机处理

### 在具体原型任务卡中要解决

1. Godot具体版本、渲染与输入验证环境、脚本语言；架构文档是建议，尚未实际采用。
2. 人形基底、骨架、比例、武器挂点、模型与动画来源，明确哪些使用占位资产。
3. 第一套轻重攻击、反击及资源技能的具体动作；逐阶段移动、转向、取消与资源事件。
4. 人形与巨兽候选的动作、可命中部位和破坏结果，不要求先写完整生态史。
5. 不足耐力能否发动最后一次翻滚、翻滚耗尽后的其他权限；弹反连续点按、失败转格挡和成本等先写明测试方案，不擅自视为已经确定。
6. 逻辑位移或根运动的样例约定、唯一运动写入入口、输入映射及调试入口。

以上不需变成一串逐项审批；有充分依据的可逆技术选择可在具体授权任务内采用注明的测试值。涉及改变已确认玩法或显著扩充范围时，再带着影响讨论。

### 在战斗与资产证据形成后再收敛

- 首版实际开放哪些大陆局部、职业专精、出身序章和剧情段落，以及主要敌人与装备的总量。
- 五大陆正式地图、文化、政治与主角完整个人线；不要在基础比例和生产效率未知时先承诺全部区域细节。
- 猎手与御灵者最终机制、法师与御灵者召唤边界、暂缓武器子类表。
- 正式伤害公式、成长曲线、掉落概率、保底次数、制作成本与通关后等级区间。
- 装备负重、称号效果、特殊药品、各套装门槛、生活活动品种和完整环境覆盖。
- 整体制作周期和完成日期，不用设计文档量估算生产速度。
